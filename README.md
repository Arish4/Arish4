## About

I'm a Software Development Engineer at **Nuvr**, where I joined as an intern and moved to SDE 1 in three months. Most of my work sits on the backend: REST API design, database performance, and self-hosted infrastructure.

- Built a rotating residential proxy network on WireGuard, headscale, GOST and AWS EC2 across 5 exit nodes. Scrape success went from near 0% to over 95%, and cut roughly ₹10L a year in proxy spend.
- Tuned PostgreSQL and ClickHouse execution plans and indexes: 35% lower query latency, 40% higher pipeline throughput on ~10k daily records.
- Shipped 8+ production features in React, TypeScript and Django REST for a platform serving 50+ enterprise clients.
- Ran two-week sprints and code review for a team of 5.

Before Nuvr: a MERN job portal at BluParrot Technologies, and a React Native emergency alert app at Finixa Dedecons that reached 500+ users.

**B.Tech in Information Technology** — Axis Institute of Technology and Management, Kanpur (2025)
